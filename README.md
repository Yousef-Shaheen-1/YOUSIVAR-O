# YOUSIVAR–Ω

منصة رقمية ثنائية اللغة لعرض المشاريع والأدوات والأنظمة والملف التقني، مع لوحة إدارة خاصة، صلاحيات خادمية، تخزين PostgreSQL، ورفع وسائط إلى تخزين Replit.

## ما يعمل الآن

- موقع عام عربي/إنجليزي بمسارات RTL/LTR، يعرض المحتوى المنشور والملف الذي يحفظه المالك.
- لوحة إدارة للمحتوى (إنشاء، تعديل، حذف، نشر، إلغاء نشر)، والملف الشخصي وإعدادات الموقع.
- مصادقة Clerk، مع التحقق من الدور والصلاحيات في Express، لا في الواجهة فقط.
- أدوار `OWNER` و`SUPER_ADMIN` و`ADMIN` و`PARTNER` و`CUSTOM_ROLE`، مع سجل تغييرات إداري.
- رفع مباشر لملفات الوسائط إلى Replit Object Storage، والتحقق من نوع الملف وحجمه وتوقيعه، وتعقيم SVG، والإبقاء على الملفات خاصة حتى النشر.
- استيراد بيانات المستودعات العامة من GitHub كمسودات.
- إعدادات مزودي OpenAI وGemini وGroq وOllama. يتصل OpenAI مباشرة من الخادم باستخدام `OPENAI_API_KEY` في Replit Secrets؛ المفاتيح لا تُرسل للمتصفح ولا تُخزن في قاعدة البيانات.
- لوحة AI للمشرف المصرح له، مع إعدادات سلوك المساعد ومحادثة اختبار.
- PWA بملف manifest وذاكرة مؤقتة لقشرة الموقع الثابتة فقط؛ لا تُخزن استجابات API أو بيانات جلسات الدخول دون اتصال.

لا تُضاف عناصر محتوى افتراضية. إذا لم ينشر المالك محتوى بعد، تظهر حالة فارغة واضحة. الاستيراد الخاص من GitHub، ومكتبة وسائط مستقلة، وتاريخ محادثات دائم ليست ضمن التنفيذ الحالي.

## متطلبات التهيئة

يُنشئ المشروع نفسه ثلاث خدمات في Replit: `artifacts/api-server: API Server` و`artifacts/yousivar-omega: web` و`artifacts/mockup-sandbox: Component Preview Server`. لا تنشئ خدمات بديلة مكررة.

1. استخدم قاعدة PostgreSQL الخاصة ببيئة التطوير. يقرأ Drizzle متغير `DATABASE_URL` الذي تديره Replit.
2. أكمل إعداد Clerk المُدار في Replit Auth. يحتاج الخادم `CLERK_SECRET_KEY` و`CLERK_PUBLISHABLE_KEY`، وتحتاج الواجهة `VITE_CLERK_PUBLISHABLE_KEY`. قيمة `VITE_CLERK_PROXY_URL` هي `/api/__clerk`.
3. عيّن `OWNER_EMAIL` في متغيرات بيئة Replit إلى البريد الأساسي **المتحقق منه** لحساب المالك في Clerk. لا توجد آلية تلقائية لمنح أول مستخدم دور المالك.
4. يتطلب رفع الوسائط متغيرات Replit Object Storage: `DEFAULT_OBJECT_STORAGE_BUCKET_ID` و`PRIVATE_OBJECT_DIR` و`PUBLIC_OBJECT_SEARCH_PATHS`.
5. يعمل OpenAI عند وجود `OPENAI_API_KEY` في Replit Secrets. يتطلب Gemini أو Groq مفتاحًا منفصلًا، وتُضبط عناوين Ollama من لوحة الإدارة. لا تُدخل المفاتيح في المحادثة أو في ملفات المستودع.
6. مزود AI والمساعد معطلان حتى يُمكّنهما المالك من لوحة الإدارة. إنشاء مفتاح لا يعني تنفيذ طلب AI فعلي أو التحقق من الفوترة.

`.env.example` مرجع لأسماء الإعدادات فقط؛ لا تضع أسرارًا فعلية فيه. استخدم Replit Secrets ومتغيرات البيئة.

## التطوير والفحوص

```sh
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/yousivar-omega run dev
pnpm run typecheck
pnpm run build
pnpm --filter @workspace/api-spec run codegen
pnpm --filter @workspace/db run push
API_BASE_URL=https://<development-domain> pnpm run smoke:api
```

`push` مخصص لقاعدة التطوير. لا تستخدمه على قاعدة الإنتاج دون مراجعة المخطط والبيانات وخطوات الترحيل المناسبة. بعد تعديل `lib/api-spec/openapi.yaml` أعد توليد العميل ومخططات Zod باستخدام Orval.

### Smoke test

`scripts/smoke-api.mjs` يتحقق من استجابة الصحة والموقع والمحتوى العام، وأن واجهات الإدارة ترفض طلبات بلا جلسة. لا يسجل دخولًا ولا يختبر منح دور المالك؛ يلزم لذلك حساب Clerk مُعدّ بقيمة `OWNER_EMAIL`.

## حدود التنفيذ الحالية

- استيراد GitHub يدعم مستودعات عامة وبياناتها الوصفية فقط؛ لا يجلب المستودعات الخاصة أو ينسخ الملفات.
- محادثة AI في لوحة الإدارة اختبار حي غير محفوظ كسجل دائم. استجابات المزود وتوافر النموذج لم تُختبر بطلب مدفوع أثناء البناء.
- المساعد لا يظهر للعامة؛ الواجهة العامة لا تعرض محادثة AI.
- صفحة المحتوى تدعم إرفاق الوسائط بالمحتوى، لكنها ليست مكتبة أصول مستقلة. ملفات الوسائط المنشورة تكون عامة حتى إلغاء نشر العنصر.
- الموقع العام مترجم عربيًا وإنجليزيًا. لوحة الإدارة تتعامل مع البيانات العربية وتدعم اتجاه RTL وتبديل اللغة، لكن بعض تسميات اللوحة لا تزال بالإنجليزية.
- العمل دون اتصال يقتصر على غلاف الموقع والملفات الثابتة التي سبق تحميلها. لا يمكن إجراء عمليات الإدارة أو API دون اتصال.

## النشر

استخدم إعدادات النشر الخاصة بـ Replit لمخرجات الـ web وAPI، ثم تأكد من تهيئة القيم نفسها في بيئة الإنتاج، لا في بيئة التطوير فقط. قبل فتح الموقع للجمهور:

- عيّن `OWNER_EMAIL` لحساب Clerk الموثّق.
- تأكد من اتصال Clerk وPostgreSQL وObject Storage في البيئة المنشورة.
- طبّق تغييرات قاعدة البيانات على الإنتاج عبر مسار مراجعة منفصل؛ لا تشغّل دفع مخطط التطوير تلقائيًا على الإنتاج.
- فعّل مزود AI فقط بعد التحقق من صلاحية المفتاح والميزانية والقيود.
- اختبر صفحات عامة، وطلبات إدارية دون جلسة، وطلبات إدارية بدور محدود بعد تسجيل دخول مالك.
